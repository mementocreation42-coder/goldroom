# GoldRoom

Mac のための RAW 現像アプリ。フォルダに入った RAW と JPEG・HEIC を、一般的な現像ソフトと同じ言葉のスライダーと LUT で現像し、まとめて書き出します。

## ダウンロード

**[最新版をダウンロード](../../releases/latest)**（`GoldRoom-<版>.dmg`）

- macOS 14 以上（Apple シリコン・Intel）
- dmg を開いて GoldRoom を「アプリケーション」へドラッグ
- はじめて開くときに「Apple は検証できませんでした」と出たら、システム設定 → プライバシーとセキュリティ →「このまま開く」
- 使い方は dmg に入っている「取扱説明書」を見てください

## 写真の扱い

写真・カタログ・設定はその Mac の中だけに置かれ、外には送りません。ネットにつなぐのは、新しい版があるかの確認だけです（設定でオフにできます）。

## アップデート

新しい版が出ると、GoldRoom を開いたときに知らせます。ダウンロードして「アプリケーション」に置き換えれば、写真や設定はそのまま残ります。
